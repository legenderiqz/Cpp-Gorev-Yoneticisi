# Görev Yöneticisi

C++ ile geliştirilmiş, konsol üzerinden kullanılan basit ve öğrenme amaçlı bir görev yönetim uygulaması.

## Özellikler

- Görev ekleme, silme ve düzenleme
- Görevleri tamamlandı olarak işaretleme veya yeniden başlatma
- Görevleri listeleme ve anahtar kelimeyle arama
- Tüm görevleri temizleme
- Görevleri `tasks.txt` dosyasına kaydetme ve dosyadan yükleme

## Gereksinimler

- C++11 destekleyen bir derleyici (ör. GCC)

## Derleme ve çalıştırma

Windows PowerShell’de g++ kurulu bir proje klasöründe sırasıyla:

```powershell
g++ main.cpp -o main
```
```powershell
.\main.exe
```
yazabilirsiniz.
